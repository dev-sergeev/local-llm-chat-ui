# Offline wheelhouse

Этот каталог содержит зафиксированный набор зависимостей для CPython 3.11, Linux x86_64 и glibc 2.17+. `MANIFEST.sha256` покрывает каждый wheel; `start.sh` проверяет манифест до установки.

Для обновления bundle на машине с разрешённым политикой package index выполните:

```bash
./scripts/build-wheelhouse.sh
```

После этого перенесите весь репозиторий вместе с содержимым `wheelhouse/` на целевой компьютер. `./start.sh` устанавливает зависимости только из этого каталога с `--no-index` и никогда не обращается в сеть.
