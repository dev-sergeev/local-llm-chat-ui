# Offline wheelhouse

В этот каталог помещаются Linux wheels для `requirements.txt` и их транзитивных зависимостей. Они намеренно не загружаются автоматически в закрытом контуре.

На совместимой Linux-машине с разрешённым package index выполните:

```bash
./scripts/build-wheelhouse.sh
```

После этого перенесите весь репозиторий вместе с содержимым `wheelhouse/` на целевой компьютер. `./start.sh` устанавливает зависимости только из этого каталога и никогда не обращается в сеть.
