# Спецификация DataLab Risk Chat

## Destination

Сохранённая в репозитории продуктово-техническая спецификация однопользовательского офлайн-чата DataLab Risk Chat, достаточная для однозначной передачи в реализацию и проверки по наблюдаемым критериям приёмки.

## Notes

- Карта планирует спецификацию; реализация сервиса в этот маршрут не входит.
- Среда — закрытая сеть без интернета. В карту, тикеты, логи и тестовые данные нельзя помещать реальные токены, банковские URL или чувствительные ответы моделей.
- Целевая платформа — Linux. Поставка должна запускаться командой `./start.sh`, не требовать Node.js во время работы, содержать заранее собранный frontend и локальный набор Python wheels.
- Приложение однопользовательское, работает только на доверенном компьютере через `localhost`, без регистрации, входа и разделения данных.
- Поддерживаются несколько профилей моделей форматов GigaChat и OpenAI-compatible. Профиль содержит стабильный внутренний ID, отображаемое название, формат, URL, токен и `model_id`; `model_id` передаётся в параметре `model`.
- UI создаёт и изменяет профили в локальном `.env`. `.env` исключён из Git; в репозитории допустим только шаблон без секретов. Токены маскируются и не попадают в логи или экспорт истории.
- История, ветки и сообщения сохраняются в локальной SQLite-базе `.data/chat.db`, исключённой из Git. После перезапуска восстанавливается последний открытый диалог.
- В чате поддерживаются текст, Markdown, блоки кода, копирование ответа и безопасное отображение разметки. Файлы, изображения, голос, web-поиск и инструменты не входят в первую версию.
- Текущие API работают только в режиме запрос–ответ. UI показывает ожидание и затем целый ответ; имитации стриминга нет. Внутренняя граница транспорта должна позволить добавить настоящие чанки позже.
- Редактирование старого сообщения пользователя создаёт новую ветку; регенерация создаёт альтернативную версию ответа. Старые варианты сохраняются и доступны для переключения.
- Профиль можно сменить перед любой генерацией. Ответ хранит несекретный снимок фактически использованного профиля; последующее изменение или удаление профиля не переписывает историю.
- Список диалогов содержит создание, поиск, сортировку по последнему изменению, автозаголовок, переименование и подтверждаемое удаление.
- Управление профилями содержит список, добавление, изменение, подтверждаемое удаление и проверку подключения. Пустое поле токена при редактировании сохраняет прежнее значение.
- Одна генерация имеет общий дедлайн 10 минут и не более трёх попыток с экспоненциальной задержкой и jitter. Повторяются сетевые ошибки, `408`, `429` и `5xx`; ошибки авторизации и прочие `4xx` не повторяются.
- Пользователь может отменить генерацию. Неуспешная генерация сохраняет пользовательское сообщение и предлагает безопасный повтор; частичный или повреждённый ответ не считается успешным.
- После падения процесса незавершённая генерация становится «прерванной» и не возобновляется автоматически. Любая внешняя операция должна иметь локальную обработку исключений и не должна завершать весь сервис.
- Вызовы LLM выполняются только через `langchain_gigachat.GigaChat` или `langchain_openai.ChatOpenAI`.
- Тикеты типа `grilling` разрешаются с использованием навыков `/grilling` и `/domain-modeling`; UI-тикет — с `/prototype`; архитектурный тикет — с терминологией глубоких модулей из `/codebase-design`.

## Not yet specified

- Провайдер-специфичные поля авторизации, TLS, сертификатов и прокси, которые могут обнаружиться после проверки закрытых API-контрактов.
- Дополнительные состояния данных или интерфейса, которые обнаружатся при моделировании веток, отмены и восстановления после сбоев.
- Требования к миграции повреждённых или устаревших `.env` и SQLite-файлов, если решение о гарантиях хранения покажет, что они нужны в первой версии.
- Варианты обновления автономной поставки, зависящие от точной Linux-среды и выбранных границ модулей.

## Out of scope

- Реализация приложения в рамках этой карты; результат карты — спецификация для последующей разработки.
- Многопользовательский режим, пользовательская аутентификация, роли и доступ к сервису не через `localhost`.
- Файлы, изображения, голос, web-поиск, RAG, плагины и вызов инструментов.
- Настоящий streaming в первой версии и искусственная имитация потоковой печати; остаётся только совместимая точка расширения.
- Облачная синхронизация истории и профилей.
- Поддержка Windows и macOS.
