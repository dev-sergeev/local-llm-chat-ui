# Local LLM Chat UI

Однопользовательский локальный чат для работы с LLM через сохранённые подключения. Контекст фиксирует язык продукта, чтобы спецификация, интерфейс и реализация одинаково называли ключевые сущности.

## Language

**Локальный пользователь**:
Единственный человек, работающий с приложением на доверенном компьютере через `localhost`.
_Avoid_: Аккаунт, клиент, арендатор

**Профиль модели**:
Именованное сохранённое подключение к LLM через один формат API. Несколько профилей могут указывать на одинаковые модели или использовать разные форматы, адреса и токены.
_Avoid_: Модель, провайдер, конфигурация модели

**Отображаемое название**:
Понятная пользователю подпись профиля модели, которая показывается в интерфейсе и не отправляется в LLM API.
_Avoid_: Имя модели, Model ID

**Идентификатор модели**:
Техническое значение профиля, которое передаётся в параметре `model` запроса к LLM API.
_Avoid_: Отображаемое название, название профиля

**Формат API**:
Контракт взаимодействия профиля модели с удалённой LLM; в первой версии допустимы GigaChat и OpenAI-compatible.
_Avoid_: Модель, адрес модели

**Активный профиль**:
Профиль модели, выбранный для следующей генерации в текущем диалоге. Его смена не изменяет уже сохранённые ответы.
_Avoid_: Текущая модель

**Диалог**:
Сохраняемая беседа локального пользователя с LLM, имеющая название, активную ветку и выбранный профиль для следующей генерации.
_Avoid_: Сессия, тред

**Ветка диалога**:
Один последовательный путь через версии сообщений диалога. Редактирование старого сообщения или регенерация ответа создаёт альтернативный путь, не уничтожая прежний.
_Avoid_: Копия диалога, перезаписанная история

**Версия ответа**:
Один из альтернативных ответов ассистента на одинаковый предшествующий контекст, созданный регенерацией.
_Avoid_: Дубликат сообщения

**История диалогов**:
Диалоги, ветки и сообщения, сохранённые локально между перезапусками приложения.
_Avoid_: Память модели, облачная история

**Сообщение в очереди**:
Отправленный во время активной генерации следующий запрос пользователя. Он хранится отдельно от ветки, запускается строго после предыдущего успешного или отменённого запроса и переживает перезапуск сервиса.
_Avoid_: Параллельная генерация, черновик

**Снимок модели**:
Неизменяемые несекретные сведения о профиле, сохранённые вместе с ответом ассистента, чтобы история оставалась понятной после изменения или удаления профиля.
_Avoid_: Профиль модели
