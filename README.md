# DataLab Risk Chat

Однопользовательский localhost-чат для работы с корпоративными LLM в закрытом контуре. Поддерживает несколько профилей GigaChat и OpenAI-compatible, ветвящуюся историю, редактирование сообщений, регенерацию, смену профиля и восстановление после сбоев.

## Быстрый запуск

Требования для полностью автономной поставки: Linux x86_64 с glibc 2.17+, CPython 3.11 и современный браузер. Node.js во время работы не нужен.

```bash
./start.sh
```

Скрипт проверит SHA-256 локального wheelhouse, создаст `.venv`, установит зависимости строго с `--no-index`, запустит сервис на `http://127.0.0.1:8765` и попробует открыть браузер.

При первом входе:

1. Нажмите «Добавить профиль».
2. Укажите название, формат API, URL, токен и `Model ID`.
3. Сохраните профиль и нажмите «Проверить».
4. Создайте диалог и отправьте сообщение.

Другой порт или сервер без графической оболочки:

```bash
./start.sh --port 9000 --no-browser
```

## Офлайн-поставка

Репозиторий уже содержит полный зафиксированный набор из 38 wheels для CPython 3.11 / Linux x86_64. Для регенерации набора на разрешённой staging-машине с package index:

```bash
./scripts/build-wheelhouse.sh
```

Перенесите весь репозиторий вместе с `wheelhouse/` по разрешённому носителю и выполните `./start.sh`. Относительный `MANIFEST.sha256` проверяется до установки; затем выполняются `pip --no-index` и `pip check`.

## Поддерживаемые подключения

Каждый профиль имеет отдельное отображаемое название и четыре параметра подключения:

- `format`: `gigachat` или `openai`;
- `base_url`: адрес API;
- `token`: локальный секрет;
- `model_id`: значение параметра `model` в запросе.

GigaChat вызывается через `langchain_gigachat.GigaChat` с токеном в `access_token`; OpenAI-compatible — через `langchain_openai.ChatOpenAI` с `api_key`. Оба адаптера получают `base_url`, `model` и отключённые внутренние повторы — общей политикой повторов управляет приложение.

Текущие банковские API работают в режиме запрос–ответ. Интерфейс показывает честное ожидание и затем полный ответ, не имитируя streaming. Пока модель отвечает, поле ввода остаётся доступным: новые сообщения сохраняются в устойчивую FIFO-очередь и выполняются последовательно с правильным контекстом. Кнопка «Остановить» сразу прекращает ожидание и запрещает сохранение позднего ответа. Внутренний транспорт допускает добавление настоящих чанков позже.

## Локальные данные и секреты

- `.env` — профили моделей и токены, права `0600`, исключён из Git;
- `.data/chat.db` — SQLite-история и ветки, права `0600`, исключён из Git;
- `.data/app.log` — ротируемый технический лог без тел запросов и токенов;
- `.env.example` — безопасный шаблон без профилей и ключей.

Сервис привязан только к loopback, проверяет `Host`, принимает изменяющие запросы только как JSON и отклоняет cross-site запросы. Локальные browser-оболочки и preview-прокси, сохраняющие loopback `Host`, могут переписывать `Origin`: официальный UI совместим с ними через служебный заголовок без включения CORS. Markdown безопасно экранируется. Локальный `.env` не зашифрован: модель угроз предполагает одного пользователя на доверенном компьютере.

## Отказоустойчивость

- общий дедлайн генерации — не более 10 минут;
- до трёх попыток с exponential backoff и jitter;
- повторяются сетевые ошибки, `408`, `429` и `5xx`;
- ошибки авторизации и другие `4xx` не повторяются;
- отменённый или поздний ответ не записывается;
- сообщения, отправленные во время ответа, сохраняются в SQLite-очереди и не теряются при перезапуске;
- ошибка генерации приостанавливает её очередь до успешного повтора, а отмена запускает следующее сообщение;
- одновременно выполняются не более четырёх генераций и четырёх внешних вызовов; зависший транспорт не создаёт неограниченное число потоков;
- незавершённая операция после рестарта получает статус «прервана» и кнопку повтора;
- ошибка одного запроса не останавливает сервис.

## Проверка репозитория

```bash
./scripts/test.sh
```

Набор включает Python behavioral/integration/smoke-тесты, Node-тест безопасного Markdown и проверку синтаксиса frontend. Python-тесты используют настоящие временные `.env`, SQLite и localhost-сервер; заменяется только внешний LLM.

## Структура

```text
src/datalab_chat/
├── application.py      # пользовательские сценарии
├── profiles.py         # атомарный каталог профилей в .env
├── memory.py           # SQLite, ветки и версии
├── generation.py       # дедлайн, повторы, отмена, recovery
├── gateways.py         # GigaChat/OpenAI LangChain-адаптеры
├── web.py              # localhost HTTP и защитные заголовки
└── static/             # полностью локальный browser UI
```
