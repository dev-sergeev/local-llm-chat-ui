# Запуск и эксплуатация

## Установка и запуск

Для запуска требуется Python 3.10 или новее, если выбранный интерпретатор поддерживается текущими версиями зависимостей. Рекомендуемый вариант использует `uv`:

```bash
uv sync
uv run local-llm-chat
```

`uv sync` создаёт виртуальное окружение и устанавливает зависимости проекта. При запуске сервис слушает `127.0.0.1:8765` и открывает браузер автоматически.

Версию интерпрета можно задать командой `uv sync --python 3.13`. Если каталог `.venv` недоступен для записи, укажите другой каталог и оставьте переменную заданной для запуска:

```bash
export UV_PROJECT_ENVIRONMENT="$PWD/.uv-venv"
uv sync --python 3.13
uv run local-llm-chat
```

Альтернативная установка через `pip`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .
local-llm-chat
```

Параметры можно передавать непосредственно команде запуска:

```bash
uv run local-llm-chat --port 9000
uv run local-llm-chat --no-browser
```

Port-forwarding, preview- и reverse-прокси работают без дополнительного флага: сервис не фильтрует запросы по `Host` или `Origin` и не защищает от DNS rebinding. Python-процесс по-прежнему слушает `127.0.0.1`, а внешний адрес и доступ пользователей определяет прокси. Встроенной аутентификации нет: каждый, кому доступен опубликованный адрес, сможет читать историю и менять локальные профили моделей.

При установке через `pip` используйте те же аргументы с командой `local-llm-chat`. Внешний bind намеренно запрещён. Остановка — `Ctrl+C` или `SIGTERM`; новые ответы после отмены не записываются. Кнопка «Остановить» немедленно меняет локальное состояние и отбрасывает поздний ответ, но синхронный запрос–ответ transport может занимать свой ограниченный слот до сетевого завершения или тайм-аута.

Пути можно изменить аргументами `--env-file` и `--data-dir`. Для штатной эксплуатации рекомендуется оставить локальные `.env` и `.data/` в корне проекта.

## Данные

SQLite работает в WAL-режиме. Главный файл и sidecar-файлы получают права `0600`; каталог `.data` — `0700`. `.env` обновляется через временный файл, `fsync`, атомарный `os.replace` и `fsync` родительского каталога, сохраняя посторонние переменные вне управляемого блока. При чтении права существующего файла приводятся к `0600`. Значения управляемого блока записываются в безопасных POSIX single quotes: `$`, обратные кавычки и подстановки команд остаются буквальными даже при чтении файла через shell.

Для резервной копии:

1. Остановите сервис.
2. Скопируйте `.env` и весь каталог `.data/` в защищённое место.
3. Ограничьте доступ к копии: `.env` содержит реальные токены.

Для восстановления остановите сервис, верните оба объекта на прежнее место, проверьте права и снова выполните `uv run local-llm-chat` либо `local-llm-chat` в подготовленном окружении. Приложение не удаляет автоматически повреждённую базу; при ошибке сохраните её копию для диагностики.

## Логи и диагностика

`.data/app.log` ротируется при размере около 1 МБ, хранятся две предыдущие версии. Лог содержит старт/остановку, локальный путь запроса и класс неожиданной ошибки, но не JSON-тела, ответы модели, URL профиля или токены.

Типовые ситуации:

- «порт занят» — запустите с другим `--port`;
- интерфейс без стилей через path-prefix proxy — откройте адрес после обновления сервиса повторно; URL без завершающего `/` нормализуется автоматически;
- «LLM-библиотеки не найдены» — повторите `uv sync` либо переустановите проект командой `python -m pip install .`;
- ошибка авторизации — проверьте формат профиля, токен, URL и `Model ID`;
- ошибка сертификата — настройте доверенный CA для Python или передайте путь через `SSL_CERT_FILE`;
- генерация «прервана» — процесс завершился во время запроса; нажмите «Повторить» вручную;
- сообщение «требует внимания» в очереди — выбранный профиль удалён или изменён после отправки; уберите запись и отправьте текст с актуальным профилем;
- ошибка активной генерации — очередь этого диалога намеренно приостановлена до успешного повтора, чтобы не потерять контекст;
- SQLite не открывается — проверьте права `.data`, свободное место и целостность резервной копии.

## Обновление

Остановите сервис и сохраните резервную копию `.env` и `.data`. После обновления файлов проекта синхронизируйте окружение:

```bash
uv sync
```

При установке через `pip` активируйте виртуальное окружение и переустановите проект:

```bash
python -m pip install --upgrade .
```

Локальные `.env` и `.data/` исключены из Git и не должны перезаписываться обновлением кода.
